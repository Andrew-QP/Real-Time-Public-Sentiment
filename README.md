This project presents a real-time system that automatically collects $TSLA stock data from Yahoo Finance and scrapes tweets from X.com, formerly known as Twitter every 10 minutes. Tweets are filtered and preprocessed by removing noise such as special characters, URLs, and mentions. The system combines financial features—Open, High, Low, Close, Volume (OHLCV)—with tweet engagement metrics, including number of views, likes, replies, and retweets. Sentiment is extracted using an NLP-based emotion classifier that assigns each tweet a score indicating its relevance to 11 distinct emotion categories. Two Long Short-Term Memory (LSTM) models are trained: one using only financial data, and the other incorporating both financial and sentiment features. The performance of each model is compared to evaluate the impact of social sentiment on short-term stock price prediction. A web-based dashboard visualizes predictions updated in real time. The research and testing conducted showed that both models are successful in capturing predictions, while the financial only model provided more stable precision – the sentiment enhanced model was able to outperform during certain market conditions like volatile sessions and trading sessions with increased social media chatter relating to the individual stock. Moreover, an optimized model that implemented both prediction architectures and a signal system to determine which prediction model to follow based on market trends and conditions would increase predictive precision while maintaining relative stable performance in normal market conditions.
